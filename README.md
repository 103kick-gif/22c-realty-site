# 22세기 부동산 (22c-realty-site)

대구 지역 공장·창고·용지 매물을 소개하는 정적(static) 데모 웹사이트입니다.
서버나 데이터베이스 없이 순수 HTML/CSS/JS로만 동작하며, 매물 데이터는 브라우저의
`localStorage`에 저장됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 방문자가 보는 메인 페이지 (매물 목록, 지도로 지역 찾기, 매물 상세보기) |
| `admin.html` | 매물·지역·공지를 등록/수정/삭제하는 관리자 페이지 |
| `site-data.js` | `index.html`과 `admin.html`이 함께 쓰는 데이터 저장 헬퍼 (`localStorage` 래퍼) |

## 실행 방법

세 파일을 **같은 폴더**에 두고 `index.html`을 브라우저로 열면 됩니다. 별도의
빌드 과정이나 서버 실행이 필요 없습니다.

```bash
# 예: 폴더 안에서 정적 서버로 열어보기 (선택 사항)
npx serve .
```

## 관리자 페이지 안내

`admin.html`은 등록 코드로 잠겨 있는 데모용 관리 화면입니다. 코드는
`admin.html` 안에 하드코딩되어 있으며, 실제 매물을 등록해 운영하려면 반드시
바꿔야 합니다. 지금 구조는 프론트엔드 전용 데모라 등록·수정한 매물이 **그
브라우저에만** 저장되고, 다른 방문자나 다른 기기에는 보이지 않습니다. 여러
사람이 함께 보는 서비스로 확장하려면 서버·데이터베이스 연동이 필요합니다.

## 테스트

`tests/site-data.test.html`을 브라우저로 열면 `site-data.js`의 순수 함수
(`sqmToPy`, `esc`)에 대한 간단한 스모크 테스트를 실행하고 결과를 화면에
보여줍니다. 별도의 설치나 빌드 과정 없이 파일을 직접 열어서 확인할 수 있습니다.
